# LollaNet：显式认知模型网络与大语言模型内部神经控制的联合学习

> 历史研究稿，已被 V4 机制程序上下文工程取代，不代表当前 LollaNet 架构。

**英文暂定题目：** *LollaNet: Joint Learning of Explicit Cognitive Model Networks and Internal Neural Control for Large Language Models*

## 摘要

本文提出 LollaNet：一种与大语言模型内部神经计算耦合的显式认知模型网络。LollaNet 将数学、物理、化学、工程、金融及其他学科中具有明确机制、输入输出、适用边界和可证伪预测的洞见表示为模型节点，并通过可训练的条件性连接把这些节点组织成稀疏网络。面对给定问题、情境和目标，系统不是从一个模型列表中进行一次性检索，而是在模型网络中形成多轮激活动力学，学习哪些模型应当被激活、以什么顺序和强度传播、相互促进或抑制，以及何时停止。

被激活的显式模型不只作为文字提示提供给大语言模型。每个模型节点还关联一个可训练的内部神经控制单元，例如层级表示方向、低维子空间或参数高效适配器。模型网络的激活状态被映射为对 Transformer 不同层隐藏表示的条件性控制，使大语言模型更倾向于按照当前被激活模型的机制进行内部计算。预测、行动和真实结果组成的 Episode 同时训练模型网络的路由参数与内部神经控制参数。

本文的核心研究问题是：**显式模型之间的可训练网络结构，能否比平面检索或独立专家路由更好地组织认知模型；这种模型网络能否通过内部神经控制真实改变大语言模型的计算，而不只是改变其解释文本；模型网络与神经控制的联合训练能否泛化到未见过的模型组合和时间外任务。** 完整 LollaNet 还允许在长期结构性残差出现时，由语言模型提出语义模型的新增、修改或拆分候选，但语义演化是模型网络之外的低频慢回路，不替代本文的核心运行时架构。

## 1. 研究动机

大语言模型能够生成广泛且流畅的回答，但通常没有一组稳定、可审计、可以跨任务持续学习调用方式的显式认知模型。把“反馈回路”“瓶颈”“安全边际”或“贝叶斯更新”等名称写入 Prompt，不能证明这些模型真实参与了内部计算；让大语言模型自由选择模型，也难以根据延迟结果稳定地学习模型之间的连接、调用顺序、控制强度和信用分配。

现有模块化网络、Mixture-of-Experts、概念瓶颈、工具路由和 activation steering 已经分别说明：系统可以学习选择计算模块，人类可读概念可以成为中间接口，语言模型行为也可以通过内部表示干预而改变。因此，LollaNet 不把“检索若干模型”“加入一个 steering vector”或“让语言模型解释自己用了什么模型”作为充分创新。

LollaNet 研究的是一个更具体的联合闭环：

> **能否把具有稳定语义契约的显式认知模型组织成一个可训练网络，使网络产生的模型激活动力学进一步控制大语言模型内部的神经计算，并通过真实任务结果共同训练这两个层次？**

这意味着显式模型不是外部知识卡片，也不是匿名专家的事后标签。它们同时具有：

1. 可供人理解和检验的语义身份；
2. 可在模型网络中传播的数值状态；
3. 可影响大语言模型隐藏表示的神经控制载体；
4. 可由 Episode 结果训练和反事实评估的贡献。

## 2. 核心假设

本文检验以下五个假设。

### H1：模型网络优于平面模型选择

显式模型之间具有条件性连接和多轮传播时，系统在需要模型组合的任务上应当优于一次性 Top-k 检索或彼此独立的专家路由。

### H2：内部神经控制优于仅使用 Prompt

在使用相同模型定义和相同计算预算时，把模型激活映射为对 LLM 隐藏表示的控制，应当比只把模型名称和定义写进 Prompt 更稳定地改变预测、行动和校准。

### H3：联合训练优于分离训练

共同训练模型网络与内部控制参数，应当优于固定模型路由后单独训练 steering，或固定 steering 后单独训练路由。

### H4：模型网络支持组合泛化

系统应当能够把训练中分别学到的模型，在未见过的任务机制组合中形成新的激活路径，而不是只记住任务类别或固定 Prompt 模板。

### H5：显式语义具有因果约束力

删除、替换或打乱模型的语义契约、网络位置或神经控制载体，应当产生与模型机制相符且可预测的性能变化；否则所谓显式模型只是匿名神经模块的标签。

## 3. LollaNet 架构

### 3.1 总体表示

LollaNet 的运行时网络表示为：

$$
\mathcal{N}=(V_C,V_M,E;\Phi,\Theta^G,\Theta^I)
$$

其中：

- $V_C$ 是定义、解释、质疑、求证、创造、决策和学习等可组合能力算子；
- $V_M$ 是显式认知模型节点；
- $E$ 是能力、模型与内部控制单元之间的条件性连接；
- $\Phi$ 是模型的语义契约；
- $\Theta^G$ 是模型网络的数值参数；
- $\Theta^I$ 是映射到大语言模型内部的神经控制参数。

一次完整计算为：

```text
问题、情境与目标
    -> 任务状态编码
    -> 显式模型网络中的多轮激活与传播
    -> 形成模型激活轨迹
    -> 映射为逐层神经控制信号
    -> 改变 LLM 隐藏表示
    -> 产生预测、判断与行动
    -> 接收真实结果
    -> 联合更新模型网络和内部控制
```

### 3.2 显式模型节点

单个模型节点表示为：

$$
M_i=(\Phi_i,z_i,D_i;\theta_i^G,\theta_i^I)
$$

其中：

- $\Phi_i$：模型身份、机制、输入输出、成立前提、适用边界、失效条件和可证伪预测；
- $z_i$：当前任务中的动态模型状态；
- $D_i$：该模型关联的内部神经控制载体；
- $\theta_i^G$：节点激活、可靠度、传播和停止相关参数；
- $\theta_i^I$：神经控制的层位置、方向、强度和持续时间参数。

例如，“反馈回路模型”不能只是一段描述文本。它应当声明接收哪些变量、关系和时间信息，输出强化或抑制方向、延迟、可能状态和可观察预测。系统可以学习什么时候使用它，但不能在训练过程中把它无声地变成与反馈回路无关的匿名专家。

### 3.3 模型网络动力学

在第 $t$ 轮模型传播中，节点 $i$ 的状态更新为：

$$
z_i^{(t+1)}=
F_{\theta_i^G}\left(
 z_i^{(t)},
 x,
 g,
 s_t,
 \sum_j W_{ji}(x,g,s_t)\,T_{ji}(z_j^{(t)})
\right)
$$

其中：

- $x$ 是问题和观察；
- $g$ 是目标与约束；
- $s_t$ 是共享认知状态；
- $W_{ji}$ 是模型 $j$ 对模型 $i$ 的条件性连接强度；
- $T_{ji}$ 表示连接的促进、抑制、校准、质疑或转换语义。

模型激活强度为：

$$
a_i^{(t)}=
\operatorname{SparseGate}_{\Theta^G}
\left(z_i^{(t)},x,g,s_t\right)
$$

网络由此学习：

- 当前应该激活哪些模型；
- 模型之间应当如何传播；
- 哪些连接在当前情境中有效；
- 每个模型的激活强度和可靠度；
- 是否需要继续传播或停止；
- 最终采用哪条模型组合路径。

因此 LollaNet 的运行时状态不是一个模型集合，而是一条带有顺序、连接和强度的激活轨迹：

$$
\mathcal{R}(x,g)=
\left\{
(a_i^{(t)},W_{ij}^{(t)},s_t)
\right\}_{t=1}^{T}
$$

### 3.4 模型激活到内部神经控制的映射

每个显式模型 $M_i$ 在大语言模型第 $l$ 层关联一个控制载体：

$$
D_{i,l}
$$

$D_{i,l}$ 可以实现为：

- 单个表示方向；
- 多维表示子空间；
- 低秩 Adapter 或 LoRA；
- 条件性残差流控制模块；
- 由模型状态生成控制信号的小型神经网络。

第 $l$ 层的控制信号为：

$$
u_l=
\sum_i a_i\gamma_{i,l}D_{i,l}
+
\sum_{i,j}a_i a_j\gamma_{ij,l}D_{ij,l}
$$

第一项表示单个模型的控制，第二项表示模型组合可能产生的非加性交互。大语言模型隐藏状态更新为：

$$
\widetilde{h}_l=h_l+u_l
$$

或通过参数高效模块表示为：

$$
\widetilde{h}_l=h_l+
\operatorname{Adapter}_{u_l}(h_l)
$$

LollaNet 不假设一个认知模型对应一个神经元。一个模型可以对应分布式方向、多个层、低维子空间或条件化适配器；同一模型在不同情境中的控制强度也可以不同。

### 3.5 联合而非串联训练

模型网络和神经控制不是两个各自训练后拼接的模块。系统共同优化：

$$
\Theta=
\{\Theta^G,\Theta^I\}
$$

其中包括：

- 节点激活参数；
- 条件性连接权重；
- 调用顺序和停止条件；
- 场景可靠度和置信度校准；
- 神经方向或子空间；
- 层位置和控制强度；
- 模型组合的交互控制；
- 路由和内部干预的信用分配。

这使模型网络的激活方式能够适应内部神经控制的实际效果，内部神经控制也能够反过来适应模型在网络中的职责。

## 4. 从 Episode 结果学习

一次有效训练经验表示为：

$$
e_t=(x_t,g_t,o_t,\mathcal{R}_t,U_t,\hat{y}_t,a_t,y_t,r_t,c_t)
$$

其中：

- $x_t$：情境与任务输入；
- $g_t$：目标与约束；
- $o_t$：可获得观察；
- $\mathcal{R}_t$：模型激活轨迹；
- $U_t$：逐层神经控制信号；
- $\hat{y}_t$：事前预测或判断；
- $a_t$：建议或实际行动；
- $y_t$：真实结果；
- $r_t$：效用或任务奖励；
- $c_t$：反证、数据质量和执行条件。

综合训练目标为：

$$
\mathcal{L}=
\lambda_1\mathcal{L}_{\mathrm{task}}
+\lambda_2\mathcal{L}_{\mathrm{outcome}}
+\lambda_3\mathcal{L}_{\mathrm{calibration}}
+\lambda_4\mathcal{L}_{\mathrm{sparsity}}
+\lambda_5\mathcal{L}_{\mathrm{semantic}}
+\lambda_6\mathcal{L}_{\mathrm{faithfulness}}
+\lambda_7\mathcal{L}_{\mathrm{stability}}
+\lambda_8\mathcal{L}_{\mathrm{cost}}
$$

各项分别约束：

- 任务预测和行动质量；
- 延迟结果带来的真实收益；
- 置信度是否校准；
- 是否激活过多模型；
- 神经控制是否保持模型语义；
- 模型节点是否真实参与计算；
- 网络是否因少量经验剧烈漂移；
- 额外控制和传播成本是否可接受。

### 4.1 反事实信用分配

对节点、连接、顺序或内部控制单元进行干预：

$$
\operatorname{Contribution}(q)=
L(\mathcal{N}\setminus q)-L(\mathcal{N})
$$

其中 $q$ 可以是：

- 一个模型节点；
- 一条模型连接；
- 一段调用顺序；
- 一个层级神经方向；
- 一个模型组合控制项。

只有当移除或替换该组件后结果稳定变差，系统才把收益归因给该组件。相关性或共同激活本身不能证明贡献。

### 4.2 训练路线

第一版训练可以分为四步：

```text
1. 人工初始化模型语义契约 Phi
2. 使用带有模型需求标签的任务对路由和神经方向进行暖启动
3. 在固定 Phi 下使用 Episode 结果联合训练 Theta^G 和 Theta^I
4. 使用反事实干预、组合分布外任务和时间外结果检验网络
```

基础 LLM 在主实验中保持冻结，训练集中在模型网络、控制方向和参数高效模块上，避免把全部收益归因于大规模微调。

## 5. 低频语义演化

完整 LollaNet 允许模型库在长期经验中演化，但语义演化不是运行时模型网络的替代品。模型激活与内部控制属于高频连续学习；模型语义修改属于低频离散学习。

当固定语义下的路由和内部控制已经充分训练，而跨 Episode 的稳定残差仍然存在时，系统可以进入语义演化回路：

```text
持续残差
    -> 排除数据、执行和普通路由问题
    -> LLM 提出 amend / add / split 候选
    -> 冻结候选
    -> 重新训练候选对应的数值参数
    -> 封闭保留集和时间外验证
    -> 接受、暂缓、拒绝或回滚
```

语言模型只生成候选，不决定候选是否正确。任何语义修改都必须版本化，并与仅重新训练数值参数所带来的收益分开报告。详细触发和接受规则见 [RGSE 方法规格](lollanet-v1/02-rgse-method-spec.md)。

第一篇论文的主要实验固定 $\Phi$，集中验证显式模型网络与内部神经控制是否成立；语义演化可以作为受限扩展实验，但不应掩盖运行时架构的主要因果问题。

## 6. 实验设计

### 6.1 机制可控基准

首轮实验使用 8–12 个具有明确输入输出和可观察预测的模型节点，覆盖不同机制族，例如：

- 反馈回路与延迟；
- 瓶颈与约束；
- 守恒与资源平衡；
- 复利与非线性增长；
- 随机性与贝叶斯更新；
- 控制、稳定性和安全边际；
- 激励与代理问题；
- 路径依赖与网络效应。

构造 4–6 类机制环境，并明确每个任务实际需要的模型、模型组合、调用顺序和可检验预测。数据划分包括：

- 训练任务；
- 分布内测试；
- 未见模型组合测试；
- 干扰模型测试；
- 时间外或机制变化测试。

基准不以“解释文本看起来合理”为主要标签，而以预测、状态转移、行动结果、校准和机制识别为评价对象。

### 6.2 对照系统

所有方法使用相同基础 LLM、数据切分、模型库和主要计算预算：

1. 基础 LLM；
2. 把全部模型定义放入 Prompt；
3. 语义检索后把 Top-k 模型放入 Prompt；
4. 由 LLM 自由选择模型；
5. 平面可训练模型路由器，不学习模型间连接；
6. reasoning-vector 或 steering-vector 路由器；
7. 固定模型图，不进行内部神经控制；
8. 内部神经控制，但不使用模型图；
9. 可训练模型图 + 固定神经方向；
10. 固定模型图 + 可训练神经方向；
11. 完整联合训练的 LollaNet。

这组对照分别回答：网络结构是否必要、内部控制是否必要，以及联合训练是否必要。

### 6.3 核心指标

报告：

- 任务预测和行动效用；
- 校准误差与不确定性质量；
- 模型选择 precision、recall 和路径一致性；
- 未见模型组合上的泛化；
- 时间外稳定性；
- 路由稀疏度、传播轮数和计算成本；
- 内部干预对无关任务的负迁移；
- 节点、边、顺序和控制方向的增量贡献；
- 多个随机种子和多个基础模型上的稳定性。

### 6.4 忠实性与因果干预

必须执行以下干预：

```text
删除已激活模型节点
删除关键模型连接
交换两个模型的调用顺序
打乱模型名称
打乱语义契约与控制方向的对应关系
把正确模型替换为机制相反的模型
保留相同 Prompt 但关闭内部控制
保留内部控制但关闭模型网络传播
关闭模型交互项，只保留方向线性相加
```

如果打乱模型语义或方向对应关系后性能不下降，说明节点语义没有真实约束神经计算；如果平面路由与模型图等效，说明模型之间的网络结构没有独立价值；如果 Prompt-only 与内部控制等效，说明神经控制没有必要。

### 6.5 现实验证

金融时间序列和决策任务可以作为第二层现实验证，但不作为架构成立的唯一证据。使用严格的时间顺序划分和滚动前推，模型定义、路由训练和神经控制构造只能使用当时可获得的信息。报告预测质量、校准、净结果、最大回撤、尾部损失、换手、时间外稳定性和多重试验控制。

跨学科模型的价值必须通过增量预测或行动质量证明，不能因为模型来自数学、物理、化学或工程就默认它适用于金融。

## 7. 预期贡献

本文预期贡献为：

1. **显式模型网络表示：** 将具有机制、边界和可证伪预测的认知模型表示为具有动态状态和条件性连接的可训练网络节点，而不是平面模型库。
2. **语义到神经的耦合机制：** 将模型网络的激活状态映射为对大语言模型不同层隐藏表示的条件性控制。
3. **联合学习方法：** 从 Episode 结果中共同学习模型选择、连接、顺序、停止条件、神经方向、层位置和控制强度。
4. **因果忠实性检验：** 通过节点、边、顺序、语义和内部方向干预，检验显式模型是否真实参与计算。
5. **组合泛化基准：** 评价模型网络能否在未见模型组合和时间外任务中形成新的有效通路。

论文不主张：

- 发明了一种新的 Transformer 基础架构；
- 一个显式模型对应一个神经元；
- 仅凭可读解释证明模型被使用；
- 所有跨学科模型天然适用于所有任务；
- 已经实现无限制、自主在线语义演化；
- LollaNet 已经等同于人脑或通用智能。

## 8. 成功与失败条件

### 成功条件

以下结果同时成立时，才能支持主要主张：

1. 模型图网络在相同预算下优于平面模型路由；
2. 内部神经控制优于只使用模型 Prompt；
3. 联合训练优于分别训练模型网络和神经方向；
4. 收益能够泛化到未见模型组合和时间外任务；
5. 路由保持稀疏，未通过激活全部模型获得收益；
6. 节点、连接和神经方向干预产生与语义机制一致的变化；
7. 内部控制没有造成不可接受的通用能力损伤。

### 失败条件

以下结果会削弱或否定主要主张：

- 平面 Top-k 路由与模型网络等效；
- Prompt-only 与内部神经控制等效；
- 固定方向与学习方向等效；
- 打乱模型名称、语义和控制方向后性能不下降；
- 模型网络只记住任务类别，没有组合泛化；
- 收益只存在于单一数据集、单一基础模型或单一随机种子；
- 内部控制主要改变措辞，不改变预测、行动或校准；
- 控制收益伴随严重的无关能力损伤；
- 模型数量和传播成本增长失控。

若模型图没有独立价值，论文应收缩为“显式认知模型的内部神经路由”；若内部神经控制没有独立价值，则应收缩为“可训练显式模型网络”；若模型语义干预不影响结果，应停止声称显式模型真实参与了神经计算。

## 9. 研究推进顺序

```text
第一阶段：固定语义模型网络
    -> 定义 8–12 个可计算模型契约
    -> 构建机制可控任务
    -> 实现平面路由与图网络路由
    -> 验证模型网络是否优于模型集合

第二阶段：内部神经控制
    -> 为模型节点学习层级方向或适配器
    -> 实现模型激活到神经控制的映射
    -> 比较 Prompt-only、固定 steering 与动态控制

第三阶段：联合训练与信用分配
    -> 联合训练 Theta^G 和 Theta^I
    -> 执行节点、边、顺序和方向的反事实干预
    -> 验证组合泛化和时间外稳定性

第四阶段：受限语义演化
    -> 在核心架构成立后接入 RGSE
    -> 允许 LLM 提出 amend / add / split 候选
    -> 使用封闭集和时间外结果决定是否接受
```

当前最优先的工作不是继续增加模型数量，而是完成一个可以区分以下四种系统的最小实验：

```text
平面模型路由
模型图网络
内部神经控制
模型图网络 + 内部神经控制联合训练
```

## 10. 一句话定义

> **LollaNet 是一个由显式认知模型节点组成的可训练网络。它根据问题和目标形成多轮模型激活轨迹，并把该轨迹映射成对大语言模型内部隐藏表示的条件性神经控制，使模型的语义选择真实影响 LLM 的计算；网络连接、激活路径和神经控制参数再由预测、行动和真实结果共同训练。**
