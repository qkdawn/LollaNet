# LollaNet 游戏策划模型

本目录包含全部公共模型在游戏策划中的直接用法。这里不修改母模型、不登记正式关系，也不假定模型对所有游戏都有效。

## 使用规则

1. 先提出具体策划决策和最少事实，再选卡；不要按学科整包调用。
2. 每次只保留会改变机制、预测、原型或行动阈值的卡。
3. 直接使用类可进入策划实验；结构映射类必须明确变量；玩法机制类只用于规则、模拟或题材。
4. 证据、公式和正式边界回到母卡；策划数据不能自动修改公共模型。
