# Value Function

The real file is private and belongs under `private/me/Value Function.md`.

This is not a fixed mathematical utility function. It records what the user currently endorses as intrinsically valuable, what must not be traded away, and where value conflicts remain unresolved. Global numeric weights are forbidden unless the user explicitly authors and bounds them for a specific context.
