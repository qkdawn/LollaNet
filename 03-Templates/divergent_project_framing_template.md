# 发散项目建模模板

用于尚未定型的创意、产品、研究、媒介或项目直觉。此模板只帮助比较不同的问题表述；它不是决策记录、项目档案、模型变更 proposal 或真实任务日志。

默认不保存实例。用户明确选择保存时，真实材料只能进入 `private/evaluations/`、`private/projects/<project_id>/reviews/` 或已授权的私人项目位置；不得把真实用户、未公开项目或专有资料写入公共目录。

## 使用门

仅当以下至少两项仍不稳定时使用：核心用户、价值、作品/交付物、交互机制、成功标准、问题本体，或“为何必须是该媒介而不是现有替代方式”。

不要把模型、学科或命题数量当作证据强度。先形成竞争性命题，后由用户或证据选择暂定命题；在此之前不得把单一技术架构、MVP 或路线图伪装成答案。

## 边界

- 不要将一次发散结果写成模型事实。
- 不要自动创建 proposal、项目记录或模型修改。
- 不要因为一次结果改变模型状态。
