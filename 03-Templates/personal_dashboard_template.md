# Personal Dashboard

The real file is private and belongs under `private/me/dashboard.md`.

## Formal Personal Assets

- `User Profile.md`: facts, capabilities, resources, and constraints.
- `Value Function.md`: user-chosen terminal values, hard constraints, and unresolved tensions.
- `Principles.md`: operational rules for recurring trade-offs.
- `Long-term Goals.md`: replaceable target states that must link back to values.
- `Current Focus.md`: the current 6-12 week allocation and experiments.

AI agents are read-only against formal personal assets by default. Current user statements override stale files, but do not silently rewrite them.

## Evidence And Review

- `observations/`: user statements and behavioral observations kept as evidence, not identity.
- `reviews/`: periodic checks of predictions, allocations, and outcomes.
- `proposals/proposed/`: suggested changes waiting for explicit user review.
