# LollaNet Weekly Review

公共框架不保存真实复盘。

选择性保存的真实复盘应写入：

```text
private/projects/<project_id>/reviews/
```

## 本周调用最多的模型

模型调用次数不是质量指标。只统计哪些模型真正改变了假设、预测或行动。

## 未复盘决策

在项目 Dashboard 中查看。

## 下周重点训练模型

由具体项目复盘决定。

## 模型修改提案

检查 `private/model-proposals/proposed/`。接受、拒绝或暂缓提案都应记录理由；复盘本身不得直接改正式模型。

## 评估

高价值分析可以使用盲测模板写入 `private/evaluations/`，并在 30/90 天后检查预测和时间尺度。
