# LollaNet 投资视角检查清单

## 来源与定位

本清单基于用户提供的《穷查理宝典》中文版第 99–103 页“投资原则检查清单”。下文保留原清单的十个部分及全部检查点，并以忠实转述呈现；不复制书页正文、旁注和长篇引文。

在 LollaNet 中，“投资”不仅指金钱，也包括时间、注意力、精力、健康、信誉、信任和选择权的投入。本清单用于检查稀缺资源的承诺、持有和再配置，不把人的价值、关系或尊严压成单一回报率，也不自动成为用户的正式价值或个人准则。

## 使用入口

先写明这次投入的基本结构：

- [ ] 要投入什么资源？其中哪一种最稀缺？
- [ ] 希望获得什么结果，依赖什么机制？
- [ ] 同一资源可支持的最佳可行替代项是什么？
- [ ] 最大可承受损失、不可逾越的边界和退出条件是什么？
- [ ] 观察窗口、复查日期和能够改变判断的证据是什么？

然后按当前任务选择下列真正会改变假设、预测或行动的部分。不要为了完成表格而机械勾选全部条目。

## 1. 风险

先衡量风险，尤其检查信用和对手方风险。

- [ ] 是否为估计误差、波动和未知因素保留了适当的[[安全边际]]？
- [ ] 是否避开品行或道德存在重大问题的交易、合作对象？
- [ ] 承担可预见风险前，是否要求了与风险相称的补偿？
- [ ] 是否把通货膨胀和利率变化纳入判断？
- [ ] 是否优先避免足以造成严重伤害的大错，并防止资本持续流失？

## 2. 独立

客观、理性的判断需要独立思考。

- [ ] 是否先形成了自己的分析，而不是借用群体、专家或权威的结论？
- [ ] 是否记得：判断正确与否取决于分析和事实，而不取决于别人赞同还是反对？
- [ ] 是否只是随大流，从而把结果推向平均和中庸？

## 3. 准备

持续工作并做好准备，才可能在机会出现时产生洞察。

- [ ] 是否通过广泛阅读培养终身学习能力、保持好奇，并让自己每天进步一点？
- [ ] 是否把“愿意充分准备”置于单纯“渴望获胜”之前？
- [ ] 是否熟练掌握多个主要学科中真正相关的思维模型？
- [ ] 是否持续追问“为什么”，直到关键机制而非表面解释？

## 4. 谦虚

承认无知，是获得更好判断的起点。

- [ ] 是否只在自己能够明确界定的[[能力圈]]内作出实质承诺？
- [ ] 是否主动辨认并核查会否定当前判断的证据？
- [ ] 是否克制对虚假精确和错误确定性的追求？
- [ ] 是否认真检查自己有没有欺骗自己，而不是只防备被别人误导？

## 5. 严格分析

运用科学方法和有效检查表，尽量减少错误与遗漏。

- [ ] 是否区分了价值与价格、过程与行动、财富与规模？
- [ ] 是否优先掌握浅显但重要的事实，而不是沉迷深奥却无关的知识？
- [ ] 是否在分析具体业务及其机制，而不是只预测市场、宏观经济或证券价格？
- [ ] 是否同时检查总体风险与总体收益？
- [ ] 是否考虑潜在的二阶效应以及更高层次的影响？
- [ ] 是否既向前推演，也向后倒推，使用[[反向思考]]检查结论？

## 6. 配置

正确配置资本，是投资者最重要的工作之一。

- [ ] 是否用次优用途来衡量当前用途，也就是明确检查[[机会成本]]？
- [ ] 是否认识到真正出色的机会很少，并在胜算明显有利时给予足够而非象征性的投入？
- [ ] 是否避免爱上某个项目，能够依据环境与机会重新配置资源？

## 7. 耐心

耐心用于克制为了行动而行动的冲动。

- [ ] 是否避免在没有必要时打断有效的[[复利]]过程？
- [ ] 是否减少不必要的交易、税费与摩擦成本，而不是为了显得积极而频繁行动？
- [ ] 好运或超预期结果出现时，是否仍能保持头脑清醒？
- [ ] 是否既能享受结果，也能接受过程本身就是生活的一部分？

## 8. 决心

合适的机会出现并达到行动门槛后，要坚决行动。

- [ ] 别人贪婪时是否保持警惕，别人恐惧时是否仍能独立识别机会？
- [ ] 是否认识到真正的机会不会频繁出现，并在机会到来时抓住它？
- [ ] 是否已经做好准备，使自己有能力承接机会，而不是临时追逐？

## 9. 改变

学会改变，并接受无法彻底消除的复杂性。

- [ ] 是否认识并适应现实世界的真实状态，而不是要求现实迁就自己？
- [ ] 是否持续挑战并主动修正自己最偏爱的观念？
- [ ] 是否正视不喜欢的现实，尤其是最不愿面对的部分？

## 10. 专注

不要把事情无谓地复杂化，始终记住原本要完成的任务。

- [ ] 是否把声誉和正直当作极有价值、却可能迅速失去的资产来保护？
- [ ] 是否警惕妄自尊大和厌倦无聊带来的判断失真？
- [ ] 是否因为过度关注细节而忽略显而易见的关键事实？
- [ ] 是否谨慎排除无关信息，同时留意可能造成重大后果的小隐患？
- [ ] 是否直面真正的大问题，而没有把它们隐藏、延后或粉饰？

## 综合判断

- [ ] 哪个检查点真正改变了我的假设、预测或行动？
- [ ] 当前应当不投入、低成本试探、有限承诺，还是扩大投入？
- [ ] 如果关键门槛仍未核实，是否只投入获得信息所需的最小资源？
- [ ] 哪些价值、关系、健康或诚信边界不能用更高回报交换？
- [ ] 何时复盘？届时用什么结果区分“需要耐心”和“应该退出”？

## 与 LollaNet 模型的连接

| 原清单部分 | 常见相关模型 | 它们增加的检查 |
| --- | --- | --- |
| 风险 | [[安全边际]]、[[基础概率]]、[[期望值]] | 失效边界、基础分布、尾部损失与压力测试 |
| 独立 | [[确认偏误]]、[[社会认同]]、[[权威偏差]] | 群体意见是否替代了证据 |
| 准备与谦虚 | [[能力圈]]、[[过度自信]] | 能力边界、校准记录和未知量 |
| 严格分析 | [[反向思考]]、[[贝叶斯更新]]、[[非线性]] | 反证、证据更新和高阶影响 |
| 配置 | [[机会成本]]、[[瓶颈]] | 最佳替代项、稀缺资源和关键约束 |
| 耐心 | [[复利]]、[[路径依赖]] | 再投入机制、中断风险和长期锁定 |
| 决心 | [[期望值]]、[[临界点]] | 行动门槛、赔率和时机 |
| 改变 | [[反馈回路]]、[[贝叶斯更新]] | 观测信号、反馈延迟和纠偏条件 |
| 专注 | [[瓶颈]]、[[机会成本]]、[[激励机制]] | 主任务、注意力配置和代理指标 |

这张表只是候选发现入口，不是固定模型组合。复杂分析应构造至少两套竞争机制程序；每套只保留 2–5 个具有任务绑定且关系连通的模型，不按勾选数量、模型数量或固定权重得出结论。
