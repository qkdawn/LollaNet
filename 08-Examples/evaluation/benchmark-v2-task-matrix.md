# LollaNet Model Test Benchmark v2 Task Matrix

所有人物、组织、数字和约束都是虚构的。本矩阵是测试输入，不是已完成的评估结果，不预设任何模型必然胜出。实际输出、匿名映射和评分必须保存到 `private/evaluations/`。

- `S01`–`S24`：可用于 v2 系统盲测。
- 标记 `A` 的任务同时属于第一波工程模型消融；每张工程模型在三个不同任务中测试。
- 运行时使用任务中给出的全部事实；除非章程另有规定，不补充外部数据。不得把“预期检验”照抄为答案。

| ID | 领域 | 任务摘要 | 主要检验张力 | 消融目标 |

## 使用说明

1. 对系统盲测，运行全部 24 题的 `Baseline` 与 `Full`，遵守 [Model Test Protocol v2](../../07-Docs/model-test-protocol-v2.md)。
2. 对工程消融，使用 `A01`–`A12`；每次只消融一个目标模型，并保持 Full 集合与其他条件锁定。
3. 任何题目都允许得出“需要更多证据”“暂缓不可逆行动”或“模型不适用”的结论。测试失败不是要求模型强行出现。
